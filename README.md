## Descripción
Este proyecto será una página web orientada a la venta online para mi familia, dueña de un local comercial.  
La finalidad es ofrecer sus productos en internet, llegar a más clientes y contribuir al aumento de las ventas.

## Técnologías usadas
* HTML5 para el maquetado de la web.
* CSS para el estilo.
* JavaScript para la programación.
* JSON para obtener los datos de los productos a cargar en las tarjetas.

## ROAD MAP
* Etapa 1:  Se crea el esqueleto de la web con HTML, creación de index, login, registro, y se guarda en repositorio github.
* Etapa 2:  Se usa CSS para dar estilo a la web, se estructura el navbar y el footer, se crean prototipos de card. Se crea el logo de la web.
* Etapa 3:  Se redirecciona al usuario al index, luego del login. Se crea el boton de cerrar sesión. Se crea el array con las direcciones y títulos de las páginas.
* Etapa 4:  Se usa Json para obtener los productos a listar. Se agregan los productos por categoría de venta, se guarda en Local Storage el carrito, se puede comprar y eliminar los productos del carrito.
